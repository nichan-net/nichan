# Нічан

Український анонімний іміджборд на базі vichan і Tinyboard. Цей репозиторій містить код сайту, теми, панель модерації та вебмайстер для встановлення незалежної копії. Нова інсталяція починається з трьох порожніх дошок — /a/, /b/ і /int/. Приклад роботи: [nichan.net](https://nichan.net). Обговорення і побажання можете залишати на дошці [n](https://nichan.net/n). Доступні мови інтерфейсу дошок - українська і англійська. Доступні мови адмінки - лише українська.

## Фічі

Усі фічі базового [vichan](https://github.com/vichan-devel/vichan/tree/814b9246d43d)'у збережені. Але додатково тут додана купа нових приколюх. Нижче приклади деяких з них:

- **Головна.** Показує останні пости, актуальні треди і навіть слідкує за історією відвідувача, щоб показати йому що було нового за його відсутності. Параметри головної можна налаштовувати в адмінці.
- **Архів і продовження ниток.** Архівні нитки зберігають свої адреси й залишаються в пошуку. Біля бампліміту видно, скільки відповідей залишилося. Коли ліміт досягнуто, автор продовження може створити нову нитку зі взаємними посиланнями на попередню.
- **Власні дописи й відповіді.** «Мої дописи» збирає повідомлення відвідувача з різних дошок. Збережені нитки, фільтри й налаштування можна перенести в інший браузер. За бажанням вебзастосунок надсилає push-сповіщення про відповіді на ваші дописи, навіть коли сайт закрито.
- **Меми й демотиватори.** Мало хто знає, але колись модно-молодіжною штукою були демотиватори. І тому ще з самого рання існування нічану він мав інструмент їх створення, за адресою `/dm`. З часом туди додалася ще й можливість створення "мемів". Готові картинки на сервері не зберігаються і живуть виключно у браузері відвідувача.
- **Малювалка.** Стандартна оекакі замінена на **Dead Paint** із проєкту [https://github.com/dead-guru/devichan](devichan).
- **Статистика.** На сайті, дошці й у нитці видно кількість відвідувачів онлайн та за останні 24 години. Сторінка статистики показує графік нових дописів за днями й швидкість дошок у дописах на годину.
- **Керування сайтом.** Оригінальний вічан мав дуже обмежену можливість налаштування. Тут же адмінка розширена, має купу підменю і можливість тонкого налаштування.
- **Капча.** Сайт має аж три різні капчі. Вбудовану англійську капчу, вбудовану українську капчу і гуглівську рекапчу (потрібен ваш API ключ). Налаштування тонке, можна налаштувати різні капчі не лише на різні дошки, але й на різні країни. Хочеш одним дати капчу, іншим вільний постинг, а третіх заблокувати? Тепер ти це можеш.
- **Захист від рейдів.** Премодерація нових тредів, обмеження швидкості створення тредів, відповідей, автоматична тимчасова заборона на створення нових тредів, автоматичне блокування постингу.
- **Обробка медіа.** Крім стандартний файлів картинок, нічан ще й підтримує webp.
- **Кольорові тріпкоди.** Фіча була додана ще у старі часи, коли сайт існував на вакабі як жарт, що людина-донатер може отримати персональний гей-тріпкод. І хоч вона ніколи не була використана, у адмінці вона є.
- **API для застосунків.** Через `/api/v1/` клієнт може шукати дописи, публікувати відповіді, надсилати скарги й перевіряти нові відповіді. Вихідний код самого застосунку на разі залишається закритим, але може з часом поділюся і їм.

## Вимоги до програмного забезпечення

- **Вебсервер.** Apache 2.4 із `mod_rewrite` та підтримкою `.htaccess` (`AllowOverride All`) або сумісний LiteSpeed. Для інших вебсерверів пишіть реврайт-правила самі.
- **PHP 8.1 або новіша** з розширеннями `pdo_mysql`, `mbstring`, `gd`, `fileinfo`, `intl`, `curl` та `zip`. GD має підтримувати FreeType для капчі та WebP для мініатюр. Альтернативно можна використати GraphicsMagick (`gm`), але для його треба буде міняти thumb_method в instance-config.php.
- **MariaDB** з рушіями MyISAM та InnoDB. Встановлення перевірено на MariaDB 11.4.

## Встановлення
1.
   ```sh
   git clone https://github.com/nichan-net/nichan
   ```
2. Самостійно створи порожню базу даних і пароль.
3. У каталозі з `install.php` згенеруй одноразовий ключ.

   ```sh
   php install.php --token
   ```

   Якщо доступу до термінала немає, згенеруй 64 випадкові шістнадцяткові символи (0–9, a–f) у менеджері паролів і запиши їх у файл `inc/install.key` одним рядком.
4. У браузері відкрийте `твій-домен/install.php` і виконуй його вказівки.
6. Коли з’явиться повідомлення **Сайт готовий**, можеш логінитися в адмінку за адресою `твій-домен/mod.php`. Майстер збереже конфігурацію в `inc/instance-config.php`, згенерує сторінки та видалить одноразовий ключ.

## Після встановлення

- У `/mod.php` відкрийте **Сайт: назва й меню**, щоб налаштувати назву, опис, адресу, зображення в шапці й зовнішні посилання.
- У **Статичних сторінках** пропиши українські та англійські правила (якщо плануєш мати інт) і можеш поправити «Цікавинки». Через панель можна створювати дошки, змінювати їхню видимість, налаштовувати капчу та модерацію.
- Telegram, Cloudflare та інші зовнішні інтеграції, якщо потрібні налаштовуй власними ключами. Для роботи дошок вони необов’язкові. Телеграм потрібен для модерації, на нього прилітають скарги, помилки і попередження від скриптів безпеки.
- Для повторної генерації статичних сторінок запустіть із кореня сайту `php tools/rebuild.php` або скористайтеся командою перебудови в панелі.

Також рекомендую налаштувати такі крони:

- php tools/update-geoip.php - оновлює базу GeoIP для інту або інших дошок з геолокацією. Раз на тиждень буде достатньо.
- php tools/update-tor-exits.php - записує у /tmp список TOR-адрес. Необхідний для окремої модерації дописувачів з Тора (там такі збоченці живуть, що ну його нах). Якщо користуєшся Cloudflare, він не потрібен. Теж раз на тиждень буде достатньо.
- php tools/nichan-cf-watchdog.php -q - обов'язковий, якщо користуєшся Cloudflare. Перевіряє чи КФ не закешувала випадково власну сторінку "One moment please...", і якщо так, то скидає кеш. Ясна річ, потрібна інтеграція з КФ. Раз на 5 хвилин.
- php tools/nichan-backup.php - бекапить базу даних, по дефолту в /backups/nichan.
- php tools/nichan-backup.php --code - бекапить файли сайту, туди ж.
